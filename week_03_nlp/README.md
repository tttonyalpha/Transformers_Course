## More materials
  - [The Illustrated Word2Vec](https://jalammar.github.io/illustrated-word2vec/) — very intuitive visual introduction to word embeddings before moving to contextual embeddings.
  - [The Illustrated BERT, ELMo, and co.](https://jalammar.github.io/illustrated-bert/) — one of the best visual explainers of transfer learning in NLP, contextual embeddings, BERT inputs, MLM, and NSP.
  - [BERT 101 - State Of The Art NLP Model Explained](https://huggingface.co/blog/bert-101) — accessible breakdown of BERT architecture, model sizes, and intuition.
  - [BertViz: Visualize Attention in Transformer Models](https://github.com/jessevig/bertviz) — excellent interactive attention visualization for BERT, GPT-2, T5, and other Hugging Face models; works in Colab/Jupyter.
  - [exBERT: A Visual Analysis Tool to Explore Learned Representations in Transformer Models](https://aclanthology.org/2020.acl-demos.22/) — interactive tool for inspecting contextual representations and attention patterns.
  - [Improving Language Understanding with Unsupervised Learning](https://openai.com/index/language-unsupervised/) — original OpenAI post on generative pre-training and transfer to downstream tasks.
  - [The Illustrated GPT-2](https://jalammar.github.io/illustrated-gpt2/) — probably the clearest visual explanation of decoder-only transformers and autoregressive text generation.
  - [Exploring Transfer Learning with T5: the Text-To-Text Transfer Transformer](https://research.google/blog/exploring-transfer-learning-with-t5-the-text-to-text-transfer-transformer/) — official T5 blog post with helpful diagrams for the unified text-to-text view of NLP.
